## What is this?

A Touhou-themed photo tagging game. Familiar faces are hiding somewhere inside a single picture — click the spot, pick the character from the dropdown, and find them all before they eat you alive ❤️.

*Waifus are waiting for you in the frame. Find them.*

## ✨ Features

- 🎚️ **Four difficulties** — from a relaxing stroll to a Gensokyo nightmare
- 🌠 **Danmaku judgment** — spell circles, flash rings, and a MISS card for every wrong pick
- 🔄 **Reroll** — Easy mode lets you trade your 30 seconds of penalty for a fresh set of five
- 🌊 **Shuffle & restore** — miss too much and the whole board re-deals; Lunatic even drags a found character back into the pool
- 🏆 **Leaderboard per difficulty** — Easy, Normal, Hard, and Lunatic each have their own wall of fame
- 🛡️ **Server-trusted timing** — Time is computed on the server

## 🛠️ Tech Stack

**Next.js 15** (App Router) · **TypeScript** · **Tailwind CSS v3** · **Prisma** · **Neon Postgres** · **Vercel** · **framer-motion** · **Vitest**
